# ariel.so

Personal portfolio site for Ariel Bukowski. Static HTML/CSS — no build step.

## Hosting

Served via **GitHub Pages** from the `main` branch (root folder). The custom
domain `ariel.so` is configured via the `CNAME` file and DNS records at the
registrar (Namecheap).

To make changes, edit `index.html` and push to `main` — Pages redeploys
automatically.

## Files

- `index.html` — the entire site (inline CSS + a little vanilla JS for the
  scroll-driven sewing-needle animation and reveal-on-scroll).
- `assets/` — banner image and résumé PDF.
- `CNAME` — tells GitHub Pages to serve at `ariel.so`.
